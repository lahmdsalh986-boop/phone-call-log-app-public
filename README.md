# نبض — تطبيق الاتصالات

تطبيق Android أصلي بواجهة عربية RTL وتصميم ليلي/نهاري. يقرأ جهات الاتصال وسجل المكالمات الحقيقي من الجهاز ولا يسجل صوت المكالمات ولا يستخدم بيانات تجريبية.

## الميزات
- سجل المكالمات: الواردة، الصادرة، الفائتة، والمرفوضة عندما يوفرها النظام.
- جهات الاتصال الحقيقية مع البحث والاتصال.
- طلب دور تطبيق الهاتف الافتراضي.
- واجهة نبض مخصصة باللون الكحلي والنعناعي مع وضعين ليلي ونهاري.
- بناء APK تلقائي عبر GitHub Actions.

## البناء
```bash
gradle assembleDebug
```
ثم يوجد الملف في `app/build/outputs/apk/debug/app-debug.apk`.
